# 文章写作速查表

这份文件专门给写博客文章时查用。写文章时，主要编辑 `posts/` 文件夹里的 `.html` 文件；复制下面的代码，再把示例文字、网址和说明换成自己的即可。

## 最基础的文字

```html
<h2>一、这一节的大标题</h2>

<h3>① 这一节的小标题</h3>

<p>这里写一整段正文。普通文字基本都放在 p 标签里面。</p>

<small class="note">这是灰色的小字，适合写注释、翻译、资料来源或补充说明。</small>
```

- `<h2>`：文章里的大标题。
- `<h3>`：大标题下面的小标题。
- `<p>`：普通正文段落。
- `<small class="note">`：灰色小字注释。

## 链接

```html
<a class="text-link" href="https://example.com/">这里是读者能看到的链接文字</a>
```

把 `https://example.com/` 换成实际网址。链接平时会和正文颜色接近，鼠标移上去会变成蓝色。

如果要在引用框里放链接：

```html
<blockquote>
  <a class="text-link" href="https://example.com/">资料原文或参考链接</a>
</blockquote>
```

## 网络图片

```html
<img
  src="https://example.com/image.jpg"
  alt="用一句话说明这张图片是什么"
>
```

- `src`：图片的网址。
- `alt`：图片无法显示时出现的文字，也能帮助读屏软件和搜索引擎理解图片内容。
- 不需要额外设置尺寸：网站已经会让文章图片自动缩小，不会超出页面宽度。

## 带图片说明的图片

```html
<figure class="article-image">
  <img
    src="https://example.com/image.jpg"
    alt="图片内容的简短说明"
  >
  <figcaption>这里写图片下方的说明，例如：图片来源：官方公告。</figcaption>
</figure>
```

`figcaption` 就是图片下方居中的灰色说明文字。

## 引用文字

```html
<blockquote>
  这里写引用内容。<br>
  <small class="note">这里可以补充翻译、出处或自己的说明。</small>
</blockquote>
```

- `<blockquote>`：带左侧竖线的引用框。
- `<br>`：在同一段里强制换一行。

## 鼠标移上去才显示的黑色剧透块

```html
<button class="spoiler" type="button">这里写剧透、吐槽或想隐藏的文字</button>
```

平时它是黑色方块，鼠标移上去或用键盘选中时才会显示内容。它可以直接放在一段正文中：

```html
<p>这是正常正文。<button class="spoiler" type="button">这是隐藏内容</button>后面还可以继续写正文。</p>
```

## 插入 YouTube 或哔哩哔哩视频

视频必须使用平台提供的“嵌入”地址，而不是普通视频网页地址。下面的 `src` 换成你拿到的嵌入地址。

```html
<figure class="video-embed">
  <iframe
    src="https://www.youtube.com/embed/视频ID"
    title="视频标题"
    loading="lazy"
    allowfullscreen
  ></iframe>
  <figcaption>视频标题或来源说明。</figcaption>
</figure>
```

YouTube 普通链接形如：

```text
https://www.youtube.com/watch?v=HdGP9tNNDQY
```

对应嵌入地址形如：

```text
https://www.youtube.com/embed/HdGP9tNNDQY
```

哔哩哔哩的嵌入地址通常形如：

```html
<figure class="video-embed">
  <iframe
    src="https://player.bilibili.com/player.html?bvid=BV1xxxxxxxxx&page=1&danmaku=0"
    title="视频标题"
    loading="lazy"
    allowfullscreen
  ></iframe>
  <figcaption>视频标题或来源说明。</figcaption>
</figure>
```

注意：不是每个站外视频网站都允许嵌入。如果视频区域空白或报错，通常是原网站禁止了嵌入，而不是你的 HTML 写错了。

## 插入网易云音乐

```html
<figure class="music-embed">
  <iframe
    src="https://music.163.com/outchain/player?type=2&id=歌曲ID&auto=0&height=66"
    title="歌曲名 - 歌手"
    loading="lazy"
  ></iframe>
  <figcaption>音乐：歌曲名 - 歌手。来源：网易云音乐。</figcaption>
</figure>
```

把 `歌曲ID` 换成网易云歌曲链接中的数字。例如普通链接是：

```text
https://music.163.com/#/song?id=2156548410
```

那么嵌入地址中的 `歌曲ID` 就是：

```text
2156548410
```

## 一篇文章的简单骨架

新文章一开始可以直接用下面的内容，再逐步往里面补：

```html
<h2>前言</h2>
<p>这里写开头。</p>
<small class="note">写作日期：2026-08-28</small>

<h2>一、第一部分</h2>
<p>这里写正文。</p>

<h3>① 小标题</h3>
<p>这里继续写正文。</p>

<blockquote>
  这里放引用内容。<br>
  <small class="note">来源或翻译。</small>
</blockquote>

<h2>二、结语</h2>
<p>这里写总结。</p>
```

## 写完后别忘了这两步

1. 文章文件放进 `content/posts/`，例如 `my-new-post.html`。
2. 打开 `content/posts/index.js`，把这篇文章添加到文章列表；否则文章写好了也不会出现在“随记”页。

文章正文文件只需要写上面这些内容，不需要写 `<!DOCTYPE html>`、`<html>`、`<head>` 或 `<body>`；网站会自动把你的文章放进完整页面里。

## 在 VS Code 里预览整个网站

不要直接双击文章的 `.html` 文件，也不要用 Live Server 预览这个项目。文章文件只是完整网页中的一小段内容；网站还要通过 Cloudflare Worker 组合页面、访问计数和留言板。

正确的预览方法如下：

1. 在 VS Code 顶部菜单点击“终端” → “新建终端”。
2. 确认终端左侧显示的文件夹是这个项目，例如 `D:\claude\web`。
3. 输入下面这行命令，然后按 Enter：

   ```powershell
   npx wrangler dev --local
   ```

   第一次运行时，如果它询问是否下载 Wrangler，输入 `y` 并按 Enter 即可。

4. 等终端出现类似下面的提示：

   ```text
   Ready on http://127.0.0.1:8787
   ```

5. 在浏览器打开：

   ```text
   http://127.0.0.1:8787
   ```

6. 回到 VS Code 修改并保存文件（`Ctrl + S`），然后在浏览器按 `F5` 刷新，就能看到新的效果。

这个地址只在你的电脑上有效，别人无法访问；命令里的 `--local` 也表示留言板和访问计数会使用本机测试数据，不会影响线上网站的真实数据。

### 预览结束后

回到运行命令的终端，按：

```text
Ctrl + C
```

就会停止本机预览。

### 如果提示 8787 端口已经被占用

说明另一个预览可能还在运行。你可以先在旧终端按 `Ctrl + C`；或者换一个端口启动：

```powershell
npx wrangler dev --local --port 8788
```

然后浏览器改为打开：

```text
http://127.0.0.1:8788
```

### 预览和发布的区别

| 你做的事 | 别人能否看到 | 会不会影响线上网站 |
| --- | --- | --- |
| `npx wrangler dev --local` | 不能，只能自己电脑看到 | 不会 |
| 推送到 GitHub 的 `main` 分支 | 可以，Cloudflare 部署后可看到 | 会 |

所以建议养成这个顺序：**先在本机预览，确认满意后，再推送到 GitHub 发布。**
